# SWP Planner

A simple calculator for a systematic withdrawal plan (SWP) from an arbitrage fund.

Enter a starting corpus, monthly income needed, plan length, return, inflation and tax rate. The page shows whether the plan is funded, how much is left at the end, charts by year, a lower-return check, and a side-by-side comparison of three corpus amounts.

Open `index.html` in any browser. No install and no server needed.

This is an illustration only. It is not investment, tax or legal advice. It assumes a steady return, inflation applied once a year, and the tax rate you enter.
